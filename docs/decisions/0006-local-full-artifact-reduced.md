# 0006. 로컬 전체판 + Artifact 축소판
- 날짜: 2026-10-12
- 상태: 채택

## 결정
- 로컬 세션은 `--both` 로 두 파일을 만든다: **로컬 전체판** (원본 데이터 전체, 크기 제한 없음, 150 MB 넘으면 경고)과
  **Artifact 축소판** (상위 결과, 15 MB 이하 보장). cloud 세션은 `--artifact` 만.
- 축소 기준은 표마다 spec `tables.<id>.artifact = {top, sort, where, columns}`. 지정이 없고 한도를 넘으면
  가장 큰 표부터 정렬 기준 상위 행만 남기도록 자동 축소 + 경고.
- 축소 사실을 페이지에 드러낸다: 표 안내문, "(원본 N행 중)", 축소 표를 쓰는 위젯 경고, 환경 탭 "Artifact 판" (로컬 전체판 경로 포함).

## 이유
사용자 지시: "로컬이면 16MB 넘는 원본 데이터로 생성하고, 아티팩트용은 상위 결과로 만든 작은 파일. 클라우드는 아티팩트만."
조용히 줄이면 축소판의 위젯 집계(DEG 수 등)가 원본과 달라 오해를 부르므로 표시를 의무화했다.
15만 행(22 MB) 시험에서 런타임의 `Math.min.apply(null, 행)` 이 call stack 을 넘기는 버그를 찾아 고쳤다 (회귀 검사 추가).
